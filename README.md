# SkillCraft Technology – Task 02
## ⏱️ Stopwatch Web Application

A simple, interactive, and responsive **Stopwatch Web Application** developed as Task 02 during my Web Development Internship at SkillCraft Technology.

The application allows users to measure elapsed time, pause and resume the stopwatch, record lap times, and reset the timer through a clean and user-friendly interface.

## ✨ Features

- ▶️ **Start:** Start the stopwatch and track elapsed time.
- ⏸️ **Pause:** Pause the stopwatch at any moment.
- 🏁 **Lap:** Record lap times while the stopwatch is running.
- 🔄 **Reset:** Reset the stopwatch and clear recorded lap times.
- ⏱️ **Digital Timer:** Display elapsed time in hours, minutes, and seconds.
- 🎨 **Modern UI:** Dark-themed design with colorful buttons.
- 📱 **Responsive Design:** Designed to work on desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

- **HTML5** – Structures the stopwatch interface.
- **CSS3** – Styles the layout, colors, buttons, and responsive design.
- **JavaScript** – Implements timer functionality, start/pause/reset controls, and lap-time recording.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure `index.html`, `style.css`, and `script.js` are in the correct locations.
4. Open `index.html` in your web browser.
5. Click **Start** to begin timing, **Pause** to stop temporarily, **Lap** to record a lap, or **Reset** to start over.
